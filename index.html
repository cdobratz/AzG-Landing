Why leftover resources surprise you

Forgotten and AI-created

Idle disks, orphaned IPs, NAT gateways, and stopped-but-billed VMs stay after the experiment ends. An AI agent can create the same resources on Azure or AWS and never tear them down.

Free tiers and credits

Azure's 12-month free services start charging when they expire. AWS monthly limits reset and keep going. Credits run out on a date you can record before the invoice arrives.

Nothing deletes itself

azguard cleanup is a dry run until you pass --apply. A resource tagged azguard:keep=true is never deleted.

Everything You Need

🧹 Clean up forgotten resources

azguard cleanup lists idle disks, unassociated public IPs, NAT gateways, stopped-but-billed VMs, and the AWS equivalents, including resources an AI agent created. The default is a dry run. Pass --apply to delete. A resource tagged azguard:keep=true is never deleted.

📋 Free tier and credits

azguard status and azguard scan check Azure. azguard aws checks AWS. The limits files cover 12 Azure services and 13 AWS services. azguard cost shows the current month by service. azguard init records remaining Azure and AWS credits and when they expire.

🎯 Find them first

azguard resources lists the same idle and orphaned resources and prints a monthly list-price estimate. The command is read-only and does not delete anything.

⚠️ Alerts

azguard budget stores an Azure threshold from $1 to $100, and azguard status prints it when you run the command. azguard watch polls for new billable resources every 15 minutes and can notify your desktop or a webhook. azguard guard checks billable commands against a session budget.
