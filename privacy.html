The CLI

The azguard command-line tool has no telemetry client. This was checked in the AzGuard source on October 18, 2026, at commit bdeb046116f29541185f884ce6c940d44299cec8. The source contains no analytics SDK and no call that reports usage back to Poietes LLC.

When you run a command, the CLI can contact:

  • Azure and AWS APIs for that command, using credentials on your machine.
  • Public price-list endpoints (prices.azure.com and the AWS Price List API) when a cost estimate needs them.
  • A webhook URL only when you pass --webhook to azguard watch.

This website

azguard.dev is a static site. It does not ask you to create an account and it does not include an analytics script. Pages load typefaces from Google Fonts, so your browser requests those files from Google. The site is hosted on Cloudflare.
